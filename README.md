## Contenido y alcance

Apuntes, prácticas, presentaciones, guiones y código recuperados de los archivos generados disponibles entre el 21 de julio y el 21 de octubre de 2026. Los materiales localizados en este periodo corresponden a septiembre y octubre. Se conservan los formatos originales disponibles; un PDF no implica que se haya recuperado su fuente editable.

El catálogo registra las fechas de generación, las versiones disponibles y las sumas SHA-256. Las copias con contenido idéntico se guardan una sola vez. Los paquetes existentes se descomprimieron para acceder a sus archivos individualmente. Se conservan revisiones diferentes cuando su contenido cambia; su inclusión no certifica que todas sean la versión docente definitiva.

## Uso

Abre el índice de la materia para consultar sus archivos. Los programas de Python y MATLAB se conservan como materiales originales de clase y no se han vuelto a ejecutar durante esta recopilación. Los documentos mantienen sus referencias bibliográficas; las fuentes de terceros enlazadas en las conversaciones no forman parte de esta recopilación.
